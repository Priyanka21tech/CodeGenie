# CodeGenie
CodeGenie is a smart code generation and explanation tool that takes prompts,and produces structured, readable code along with clear, step-by-step explanations.

Project Structure:
CodeGenie
1. >static
      >styles.css
2. >templates
     >index.html
3. >app.py
4. >codeAPI.py

Install all the necessary packages.

Code Running steps:
1. First run the codeAPI using -
    uvicorn codeAPI:app --reload
2. Now in the integrated terminal run- python app.py
